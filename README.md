# 되감기 (Rewind) — 반도체 시장을 다시 살아보는 모의투자 게임

2019년 어느 날로 돌아가, 실제로 있었던 반도체 국면(팬데믹 폭락, 2022 긴축 하락장, AI 랠리, 엔캐리 청산, 관세 쇼크, 2026년 6월 고점 이후 급락…) 위에서
**가상의 기업 100여 곳(반도체·2차전지·바이오·방산·조선·원전·로봇·엔터·게임·코인·밈 등)과 레버리지 ETF**를 국내·해외 장에서 사고파는 웹 게임입니다. 2026년 11월 3일 이후로는 매번 다르게 생성되는 가상의 미래가 이어집니다.

## 실행

```bash
npm install
npm run dev          # 개발 서버
npm run build        # 정적 빌드 (dist/)
npm start            # dist/ + 실시간 중계를 한 포트로 서비스 (배포용)
npm run test:engine  # 엔진 검증: 2019→2027 캠페인을 헤드리스로 돌려 결정성·저장/복원 확인
```

## 주요 기능

- **두 가지 모드**
  - **역사 그대로**: 실제 날짜와 순서대로 흘러가요. "그때로 돌아가면 나는 벌까?"
  - **미지의 국면**: 실제 국면(팬데믹 폭락, 긴축 하락장, AI 랠리…)이 같은 순서로 오지만 언제, 얼마나 빨리 올지는 매번 달라요. 대체로 더 빠르게 지나가고, 전쟁 위기·은행 파산·감염병·대지진·깜짝 금리 같은 가상의 대형 사건이 수시로 끼어들어요. 연도는 항상 숨겨져서 역사를 알아도 타이밍을 못 맞혀요.
- **캠페인**: 2019년 6~12월 사이 무작위 날짜에 시작. "연도 숨기기"를 켜면 몇 년도인지 모른 채 진행돼서 다음 위기가 언제 올지 알 수 없어요.
- **두 시장, 한 계좌**: 국내(원화)·해외(달러) 탭, 자동 환전과 수동 환전, 해외 가격의 $/₩ 표시 전환.
- **실제 장 운영**: 정규장·프리·애프터·데이마켓, 미국 서머타임, 한·미 휴장일, 넥스트레이드 개장(2025.03) 전후, 미국주식 주간거래 중단(2024.08)·재개(2025.11)까지 반영.
- **국장 규칙**: 가격제한폭 ±30%, 호가단위, 공모주 첫날 범위(2023.06 제도 변경 전후), 연도별 증권거래세(근사치).
- **뉴스**: 실제 국면의 주요 사건(가상 기업명으로 각색) + 하루 수십 건의 찌라시·단신. 일부는 가격을 움직이고 대부분은 소음이에요.
- **레버리지 ETF**: 매일 배율을 다시 맞추는 실제 방식이라 횡보장에서 값이 깎이는 현상이 그대로 나타나요.
- **주문**: 시장가와 지정가(당일 유효, 호가 단위·가격제한폭 검증, 주문 금액·주식 묶어두기), 미체결 주문 취소.
- **관심 종목**: ☆로 모아 보는 관심 탭.
- **시작 자금**: 10만 원 ~ 1,000억 원 사이에서 자유롭게.
- **기업명**: 실제 기업을 반대말·숫자로 비튼 패러디 이름(예: 나노크론, 와이드컴, 아웃텔, 사성전자, 로우닉스). 사업 내용과 주가는 모두 가상이에요.
- **지수**: 코스비(코스피 패러디), 나스닭(나스닥), 업종 지수(코스비 반도체, 필라테스 반도체). 실제 지수 이름과 수치로 오해되지 않게 패러디 이름을 써요.
- **급등주(현실 모티브)**: 미장 잡주는 뉴스 갭상승 후 밀림·음전, 재료 없는 펌프 앤 덤프(장중 몇백 %), 며칠짜리 숏스퀴즈와 블로오프, 급등 뒤 유상증자 폭락. 5분에 10% 넘게 움직이면 LULD로 5분 거래정지. 국장은 상한가 직행·연상, 상한가 찍고 풀리는 장대 윗꼬리.
- **기업 이슈**: 수주·무상증자·기술수출·M&A·FDA 승인 같은 호재와 유상증자·블록딜·어닝 쇼크·임상 실패·횡령·공매도 리포트 같은 악재가 종목마다 터져요.
- **거래정지·상장폐지**: 감사의견 거절·횡령 등으로 거래정지 → 거래재개(대개 하한가) 또는 상장폐지 확정 → 정리매매(7거래일, 가격제한 없음, 가끔 "상폐빔"). 상폐되면 보유 주식은 사라져요.
- **신규 상장**: 2019~2026년에도 가상 기업이 계속 상장해요. 상장 첫날 따상(2023.06 전)·따따블(이후), 미장 IPO 대박, 그 뒤 몇 주간 흐름까지.
- **종목 순서 고정**: 목록이 저절로 움직이지 않아요. ⋮⋮를 끌어서 내 순서를 정하고, 정렬 버튼은 누른 순간 기준으로 한 번만 정렬해요.
- **테마·급등주**: 테마별 사이클(2023 2차전지 광풍, 2025 방산·조선·원전 등)과 소형주의 이유 없는 급등·상한가, 다음 날 추격 또는 되돌림. 종목 고유 움직임은 평균으로 되돌아가서 끝없이 복리로 불어나지 않아요.
- **강화소(미니게임)**: 황금 주권을 사서 +20까지 강화해요. 단계가 오를수록 비싸게 팔리지만 실패하면 유지·하락·파괴. 운으로 크게 벌 수 있지만 기대값은 살짝 마이너스예요.
- **단일종목 레버리지 ETF**: 인비디아·에디슨모터스·팔란티리 등 미장 대형주의 2X·-2X·-1X (2022년 하반기부터 상장).
- **효과음**: 매수·매도·체결·속보·장 시작 종·급등 알림·강화 결과. 설정에서 끄거나 크기 조절.
- **커뮤니티**: 성격이 다른 가상 개미 9종이 시장 상황과 내 매매·방 친구 매매에 반응해 실시간으로 글을 써요. 글을 누르면 댓글이 열리고 추천 수가 시간이 지나며 늘어나요. 시장 상황(급등·급락 종목, 지수, 뉴스, 환율, 레버리지)에 반응하는 가상의 개미 게시판. 주식 커뮤니티 말투를 흉내 내지만 혐오 표현·자해 밈은 넣지 않았어요.
- **실시간 대결 방**: 같은 방 사람들은 같은 시계·주가·뉴스를 함께 봐요. 방장이 시간을 흘려보내고, 서로의 수익률과 최근 매매가 실시간으로 보여요. 엔딩은 없어요. 방장이 나가면 가장 먼저 들어온 사람이 이어받아요.
- **방 안 대출**: 대결 방에서 친구에게 돈을 빌려줄 수 있어요. 금액·이자·기간·갚는 방식(만기 일시 / 매주 분할)을 정해 제안하고, 상대가 수락하면 송금돼요. 남은 빚, 다음 상환일과 금액, 회차별 상환 일정표, 연체 여부가 보이고, 상환일엔 자동으로 갚아요. 빚과 받을 돈은 총자산·수익률에 반영돼요.
- **세계 코드**: 같은 코드로 시작하면 친구와 같은 세계(같은 시작일·주가·뉴스)에서 플레이할 수 있어요.
- **화면**: 모바일은 하단 탭(시장/내 계좌/뉴스) + 종목 상세 + 주문 시트, 데스크톱(1080px 이상)은 3열(시장 | 차트 | 주문·계좌·뉴스).

## 구조

```
src/engine/   UI와 무관한 순수 JS (Node에서 그대로 테스트 가능)
  themes.js     대표 지수(코스비·나스닭) 기준점과 테마별 사이클
  community.js  시장 상황에 반응하는 가상 커뮤니티 글
  rng.js        시드 기반 난수. 날짜·종목마다 독립 스트림이라 어떤 날이든 재현 가능
  calendar.js   한·미 휴장일, 서머타임, 세션 시간, 제도 변경 시점, 증권거래세
  backdrop.js   2019.06~2026.11.03 실제 국면: 지수 기준점, 핵심 거래일, AI·메모리 사이클, 뉴스
  companies.js  가상 기업(베타·AI/메모리 민감도·고유 변동성·상장일)과 미래 IPO 생성
  future.js     2026.11.04 이후: 국면 전환(상승/횡보/하락), 거시 이벤트, 찌라시 템플릿
  world.js      하루 단위 지연 생성기. 일봉 뼈대 → 10초 간격 경로(브라운 브리지) → 종목·ETF·환율
  account.js    원화·달러 예수금, 체결(스프레드·수수료·세금), 자동 환전, 평가
src/net/       실시간 방: 전송(아티팩트 room / Supabase / 자체 중계), 방 규칙(방장 선출, 시계 동기화), 공개 로비
server/        배포용 Node 서버(index.mjs)와 실시간 중계(relay.mjs, 개발 서버에도 붙음)
src/ui/        React 화면 (시장 목록, 종목 상세, 주문, 계좌, 뉴스, 설정)
scripts/       엔진 검증 스크립트
```

**가격이 만들어지는 방식**
1. 시장별 지수의 하루 뼈대(시가·고가·저가·종가)를 정해요. 실제 기간에는 다음 기준점을 향해 표류하고, 핵심 거래일은 실제 등락을 1.2배로 키워 적용해요.
2. 뼈대 안에서 10초 간격 경로를 브라운 브리지로 그려요. 장 시작·마감 무렵에 더 크게 흔들리고(U자형 변동성), 시간외는 다음 날 갭을 향해 천천히 움직여요.
3. 각 종목 = 지수 × 베타 + AI·메모리 사이클 노출 + 고유 움직임 + 찌라시 충격. 국장은 가격제한폭과 호가단위로 다듬어요.
4. 저장할 때는 "오늘 시작 시점의 상태"와 일봉 기록만 남기고, 오늘 하루는 시드로 다시 만들어요. 그래서 저장 용량이 작고 복원이 정확해요.

## 실시간 대결 방 설정

세계는 시드만으로 완전히 재현되기 때문에, 방에서는 **방장의 시계·속도**와 **각자의 수익률·최근 매매**만 주고받아요(사람당 1KB 미만).
늦게 들어온 사람은 방장 시점까지 자기 기기에서 빠르게 따라잡아요. 같은 시드라 가격이 정확히 같아요(`src/net/match.js`).
참가자는 방장보다 앞서 가지 않도록 주요 뉴스 지점에서 방장과 같은 순간에 멈춰요.

**열린 방 목록(로비)**: 시작 화면에 지금 열린 방이 실시간으로 떠요. 닉네임만 적고 "참가"를 누르면 코드 없이 들어가요.
방을 만들 때 "열린 방 목록에 공개"를 끄면 방 코드를 아는 사람만 들어올 수 있어요. 방장이 나가면 이어받은 사람이 목록에 계속 올려요.

전송 방식은 세 가지를 같은 인터페이스로 지원해요(`src/net/room.js`). 위에서부터 되는 걸 써요.
1. **claude.ai 아티팩트**로 열면 내장 `room` 기능.
2. `.env`에 Supabase 값을 넣으면 Supabase Realtime Presence.
3. 그 외에는 **게임을 띄운 서버의 `/relay` 중계**(`server/relay.mjs`). 설정이 필요 없어요.

### 누구나 들어오게 배포하기 (권장: Node 서버 하나)

```bash
npm install
npm run build
npm start            # http://localhost:8080 — 게임 화면 + 실시간 중계 (PORT 환경변수로 포트 변경)
```

WebSocket을 지원하는 Node 호스팅이면 어디든 돼요(Render, Railway, Fly.io, VPS).
Render는 저장소를 연결하면 `render.yaml`대로 빌드·실행돼요. 무료 플랜은 15분 동안 아무도 없으면 잠들고, 다음 접속 때 30초쯤 걸려 깨어나요.
배포된 주소만 알려 주면 누구든 들어와서 열린 방 목록에서 바로 참가할 수 있어요.

### 실행 파일(.exe) 하나로 묶기

```bash
npm run build:exe                 # release/rewind-win-x64.exe (약 85MB)
npm run build:exe -- linux-x64    # 다른 대상: linux-x64, darwin-arm64, darwin-x64
```

Node의 단일 실행 파일(SEA) 기능으로 게임 화면·서버·실시간 중계를 파일 하나에 넣어요. 받는 사람은 Node를 설치할 필요가 없어요.
더블클릭하면 서버가 켜지고 브라우저가 열려요. 콘솔 창에 같은 와이파이 친구가 들어올 주소(`http://192.168.x.x:8080`)가 떠요. 창을 닫으면 꺼져요.
- 서명하지 않은 파일이라 처음 실행할 때 Windows SmartScreen이 막아요 → "추가 정보" → "실행".
- Windows 방화벽이 물으면 "개인 네트워크"를 허용해야 같은 와이파이 친구가 들어와요.
- exe를 켠 PC가 서버예요. 인터넷 너머 친구는 공유기 포트포워딩 없이는 못 들어와요. 친구가 각자 exe를 켜면 서로 다른 서버라 같은 방에서 못 만나요. 인터넷으로 아무나 들어오게 하려면 위의 Node 서버 배포를 쓰세요.
- 대상 플랫폼용 Node 실행 파일을 nodejs.org에서 한 번 받아 `.exe-cache/`에 둬요(빌드하는 Node와 같은 버전이어야 해서). macOS용은 macOS에서 빌드해야 서명돼서 실행돼요.

### Cloudflare Workers에 배포하기 (잠들지 않음, 무료 플랜 가능)

```bash
npx wrangler login     # 처음 한 번
npm run cf:deploy      # 빌드 + 배포 → https://stock.gagether.wiki (예비: rewind-stock.<계정>.workers.dev)
npm run cf:dev         # 로컬에서 Cloudflare 런타임으로 미리 보기 (http://localhost:8787)
```

게임 화면은 정적 에셋으로, 실시간 중계(`/relay`)는 방마다 Durable Object 하나로 돌아가요(`worker/index.js`, `wrangler.jsonc`).
`server/relay.mjs`와 주고받는 형식이 같아서 클라이언트는 그대로예요. Hibernation API를 써서 아무도 말하지 않는 방은 비용이 들지 않아요.
Render 무료 플랜과 달리 잠들지 않아서 첫 접속이 바로 떠요.

Vercel 같은 정적 호스팅에는 중계가 없으니, Supabase 값을 넣거나 중계 서버를 따로 띄워 `VITE_RELAY_URL`을 지정하세요(`.env.example`).

## 데이터와 라이선스

- 이 게임은 **실제 시세 데이터를 쓰지 않아요.** 기업·상품·가격은 모두 생성된 가상 값이고, 날짜와 사건의 흐름만 실제 국면을 참고했어요.
  그래서 친구 공유나 포트폴리오 데모로 배포해도 시세 데이터 재배포 문제가 생기지 않아요.
- 실데이터로 연습하는 모드를 붙인다면, 개인 API(예: 증권사 Open API)는 대부분 본인 사용만 허용하고 제3자 배포를 금지해요.
  그 경우 앱이 데이터를 갖지 않고 사용자가 본인 키로 받은 파일을 불러오는 방식이 맞아요.
- 수수료·세금·환전 스프레드는 근사치예요. 투자 조언이 아니에요.
